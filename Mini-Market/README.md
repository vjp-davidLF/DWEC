# Mini-Market

Tienda online con carrito de compras

## Como usar

Primero instalar:
```bash
npm install
cd server
npm install
cd ..
```

Para ejecutar:
```bash
# Terminal 1
npm run server

# Terminal 2  
npm run lanzarRAM
```

Abre el navegador en http://localhost:8080

## Que usa

- HTML, CSS, JavaScript
- Webpack para empaquetar
- json-server para la API
- IndexedDB para guardar el carrito

## Estructura

- src/js/clases - las clases principales
- src/js/pages - codigo de cada pagina
- src/templates - los html
- server/db.json - base de datos

si no funciona revisar que este corriendo el servidor json
